AIX BOX 完美集群设计方案
===============================

设计目标：从个人AI助手进化成边缘云计算网络
设计原则：乐高式物理扩展 + 细胞式网络自治 + 水电式服务计费

一、物理层：六大功能模块
-----------------------------

模块          核心配置                     价格预估     适用场景
------------------------------------------------------------------------
Core          J1900 + 4GB + 500GB          ¥4000        入门节点、轻量Agent
Brain         RK3588 + 8GB + 1TB           ¥6000        中等推理、多Agent调度  
Power         M4/M4 Pro + 64GB             ¥12000       大模型推理、复杂计算
Vault         4TB NVMe + 加密芯片          ¥5000        数据存储、备份节点
Link          5G + WiFi6 + 卫星模块        ¥3000        偏远地区、移动场景
Safe          HSM 2.0 + 生物识别           ¥4000        高安全需求、金融场景

卡扣接口：AIX-Connector v1.0
- 磁吸+卡扣双固定
- 触点：电源共享 + 数据总线(PCIe 4.0 x4) + 同步时钟
- 最大串联：8个Box
- 防呆设计

二、三种组网模式
-----------------------------

1. 星型主从（那耶村模式）
   [Power主控] ← 账本同步、任务调度
        │
        ├── Core终端1 (村民A)
        ├── Core终端2 (村民B)
        ├── Core终端3 (游客)
        └── Vault存储 (全村备份)

2. 对等网格（社区自治）
   无主节点，分布式共识，任意节点掉线不影响整体

3. 混合分层（商业服务）
   Layer 3: 接入层（10-100 Core）
   Layer 2: 服务层（5-10 Brain）
   Layer 1: 核心层（2-3 Power+Safe）
   Layer 0: 存储层（Vault集群）

三、那耶村MVP配置（9节点）
-----------------------------

主控节点（1个）：Power + Link
   M4 Pro 64GB + 2TB + 5G/卫星模块
   职责：大模型推理、全村账本、对外出口

服务节点（3个）：Brain
   位置：村头、村委会、民宿
   职责：日常AI服务、多语言服务

终端节点（3个）：Core
   位置：村民家中（试点）
   职责：个人数据、家庭AI助手

存储节点（2个）：Vault（8TB RAID1）
   位置：村委会（主）、村民家（备）

总成本：¥6-8万
服务：50户村民 + 日均20游客
回本周期：6-12个月

四、服务架构
-----------------------------

自用能力：
- 基础（Core）：个人助手、文档存储
- 增强（Core+Brain）：视频生成、多Agent协作
- 专业（+Power）：代码开发、复杂分析

商用能力：
- 算力出租：Power Box空闲时对外推理
- 存储出租：Vault Box提供备份空间
- 网络中继：Link Box作为mesh节点
- 计费：按次/按时/按量的Coin Hour结算

五、软件层：AIX Cluster OS
-----------------------------

- 自动发现：即插即用
- 负载均衡：任务自动分配
- 故障转移：节点掉线自动切换
- 资源调度：根据Coin Hour激励分配

六、一句话总结
-----------------------------

乐高式物理扩展 + 细胞式网络自治 + 水电式服务计费

每个Box是独立的数字主权单元，叠加后成为社区/商业的基础设施
——从"个人AI助手"进化成"边缘云计算网络"
