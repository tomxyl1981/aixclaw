# 那耶村机制设计方案

**版本**：v1.0
**日期**：2026-05-27
**理论依据**：机制设计理论（Eric Maskin，2007年诺贝尔经济学奖）+ 纳什博弈论

---

## 一、问题定义

### 1.1 三方博弈框架

```
        投资人（资金）
           │
           │ 提供资金
           │ 承担风险
           │ 期望回报
           ↓
        操盘人（运营）←──→ 村集体（土地/劳动）
           │                  │
           │ 执行运营          │ 提供土地
           │ 对接市场          │ 提供劳动力
           │ 期望分成          │ 期望分红
           │                  │
           └──────────────────┘
                    ↓
              利益冲突点？
```

### 1.2 核心矛盾

| 冲突维度 | 投资人 | 操盘人 | 村集体 |
|----------|--------|--------|--------|
| 时间偏好 | 快速回报（2-3年） | 中期变现（3-5年） | 长期稳定（代际） |
| 风险态度 | 规避风险 | 承担运营风险 | 规避风险 |
| 信息优势 | 了解资本市场 | 掌握运营实况 | 掌握本地关系 |
| 控制欲 | 想要决策权 | 想要自主权 | 想要话语权 |

## 二、社会目标定义

### 2.1 总目标

**"奇奇怪怪的人在那耶村建立新世界"**

拆解为经济目标：
- 投资人：年化回报率 ≥ 15%
- 操盘人：5年累计分成 ≥ 初始投资 × 3
- 村集体：持续Coin Hour产出 + 土地增值

### 2.2 约束条件

**约束1：资源约束**
- 总收益 ≥ 投资人回报 + 操盘人分成 + 村集体分红 + 再投资

**约束2：激励相容**
- 说真话的收益 ≥ 说谎的收益（对所有参与者）

**约束3：自愿参与**
- 参与机制的收益 ≥ 不参与的收益（对所有参与者）

## 三、机制设计方案

### 3.1 方案A：分阶段让渡机制

#### Phase 1（0-2年）：投资人主导

- 治理结构：投资人70%投票权，操盘人20%，村集体10%
- 收益分配：投资人60%净利润，操盘人30%，村集体10%+Coin Hour

#### Phase 2（2-5年）：操盘人主导

- 治理结构：投资人40%投票权，操盘人40%，村集体20%
- 收益分配：投资人40%净利润，操盘人35%，村集体25%+Coin Hour

#### Phase 3（5年+）：村集体自治

- 治理结构：投资人20%投票权，操盘人20%，村集体60%
- 收益分配：投资人30%净利润，操盘人20%，村集体50%+Coin Hour

### 3.2 方案B：Token化治理机制

**Token发行**：
- 总量：1,000,000 AIX Token
- 投资人：300,000（30%），锁定期2年
- 操盘人：200,000（20%），锁定期1年
- 村集体：500,000（50%），绑定土地

**Coin Hour机制**：
- 村集体Token每日产出10 CH/Token
- Coin Hour用于那耶村内消费

### 3.3 方案C：可验证业绩机制

**核心规则**：
- 投资人回报 = 基础收益（年化8%）+ 业绩分成
- 操盘人收入 = 基础工资 + 利润分成（20%）+ Coin Hour激励
- 村集体收入 = 土地租金 + 利润分成（30%）+ Coin Hour产出

## 四、关键约束：AIX已上市交易

### 4.1 现实情况

**AIX已在L Bank和Bitmart上市，Token可自由交易套现**

这改变了原假设：
- 原假设：Token锁定，Coin Hour绑定长期持有
- 现实：Token可卖，Coin Hour产出权可能被投机者拿走

### 4.2 问题：激励机制失效

**原逻辑**：
村集体拿Token → 每日产出Coin Hour → 本地消费 → 长期绑定

**现实逻辑**：
村集体拿Token → 立即卖掉套现 → Coin Hour产出归投机者 → 经济闭环断裂

### 4.3 解决方案

**方案2：产出绑定DID（推荐）**

```
规则：
├── Coin Hour产出绑定"村民身份"，而非Token
├── Token可自由交易，但产出权绑定DID
└── 卖掉Token后仍可产出Coin Hour（但产量降低）

计算：
├── 有Token：10 CH/Token/日
├── 无Token但有村民身份：5 CH/日（基础保障）
└── 两者叠加：最多10 CH/Token/日 + 5 CH/日
```

**优点**：
- 村民可卖Token套现（满足短期需求）
- 但仍保留基础Coin Hour产出权（绑定长期利益）
- Coin Hour本地消费闭环不因Token交易而断裂

## 五、Maskin单调性检验

### 5.1 单调性定义

如果一个社会目标违反Maskin单调性，那么没有任何机制能实现它。

### 5.2 检验案例

**场景：投资人风险偏好变化**

状态θ：投资人风险中性（接受5年回报）
状态θ'：投资人风险规避（要求3年回报）

调整方案：
- Phase 1延长至3年
- 投资人Phase 1回报提高至70%
- 操盘人Phase 1分成降至25%
- 村集体Phase 1分成降至5%

## 六、多重均衡处理

### 6.1 潜在均衡

**好均衡（合作均衡）**：
- 投资人：提供资金，信任操盘人，长期持有Token
- 操盘人：全力运营，诚实报告，建立声誉
- 村集体：积极配合，本地服务，消费Coin Hour

**坏均衡（互相猜忌）**：
- 投资人：频繁干预
- 操盘人：偷懒，夸大成本
- 村集体：观望，不配合

### 6.2 消除坏均衡

**机制1：硬件级治理**
- Token锁定期、Coin Hour产出规则写入UTXO账本

**机制2：声誉机制**
- 坏均衡导致声誉损失，未来无法合作

**机制3：惩罚机制**
- 违约成本 > 违约收益

## 八、总结

**机制设计的本质**：让三方的"利己"行为自动导向"利他"结果

**核心创新**：
- 激励相容设计替代道德说教
- 代码强制执行替代人工监督
- Coin Hour持续产出绑定长期利益

**关键更新**：
- AIX已上市，Token可自由交易
- Coin Hour产出绑定DID，而非Token
- 村民可套现但仍保留基础产出权
