## 一、三层架构定义

### 1.1 原子任务层（Atomic Tasks）

**定义**：最小不可分解单元，高复用，低价值密度

**特征**：
- 单一职责
- 输入输出明确
- 可独立测试
- 跨场景复用

**示例**：

| 原子任务 | 输入 | 输出 | 技术实现 |
|---------|------|------|---------|
| 文本分类 | 文本 | 类别标签 | ms-swift训练模型 |
| 意图识别 | 用户消息 | 意图类型 | NLU模型 |
| 数据库查询 | SQL | 结果集 | Composio连接 |
| 网页点击 | 元素选择器 | 操作结果 | Browser Harness |
| 图片生成 | 文本描述 | 图片 | Stable Diffusion |
| 语音合成 | 文本 | 音频 | ElevenLabs API |
| 记忆检索 | 查询词 | 相关记忆 | Awareness-Local |
| 知识图谱查询 | 实体/关系 | 相关节点 | Graphify |

### 1.2 分子任务层（Molecular Tasks）

**定义**：原子任务组合，中等复杂度，中复用

**特征**：
- 2-5个原子任务组合
- 特定场景有意义的流程
- 可参数化配置

**示例**：

| 分子任务 | 原子任务组合 | Coin Hour |
|---------|-------------|----------|
| 问题分类 | 文本分类 → 意图识别 → 优先级判断 | 5 CH |
| 信息检索 | 数据库查询 → 记忆检索 → Tavily搜索 | 10 CH |
| 内容发布 | 内容生成 → 图片生成 → Browser Harness发布 | 30 CH |
| 会议准备 | 日历查询 → 记忆检索 → 议程生成 → 通知发送 | 20 CH |
| 订单处理 | 订单查询 → 状态判断 → 方案生成 → 通知客户 | 15 CH |

### 1.3 复合任务层（Composite Tasks）

**定义**：完整业务流程，低复用高价值

**特征**：
- 10+原子任务组合
- 端到端业务闭环
- 直接产生商业价值

**示例**：

| 复合任务 | 分子任务组合 | Coin Hour | 商业价值 |
|---------|-------------|----------|---------|
| 客服对话全流程 | 问题分类 → 信息检索 → 方案生成 → 回复生成 → 满意度跟踪 | 50-100 CH | 替代客服人员 |
| 梯田导览服务 | 游客分析 → 路线规划 → 文化讲解 → 服务推荐 → 反馈收集 | 100-200 CH | 旅游转化 |
| 短剧制作发布 | 剧本生成 → 分镜设计 → 配音配乐 → 渲染导出 → 平台发布 | 200-500 CH | 内容变现 |
| 行业调研报告 | 数据收集 → 分析洞察 → 报告生成 → 可视化 → 引用核查 | 150-300 CH | 决策支持 |

## 三、系统级杠杆计算

### 3.1 当前设计统计

| 层级 | 数量 | 来源 |
|------|------|------|
| 原子任务 | ~50个 | 10大能力拆解 |
| 分子任务 | ~40个 | 平均每能力4个 |
| 复合任务 | 10个 | 一人公司10大能力 |

### 3.2 杠杆潜力

```
当前设计：
50个原子任务 × 平均组合数3 = 150种分子任务潜力
实际设计了40种分子任务

40种分子任务 × 平均组合数4 = 160种复合任务潜力
实际设计了10种复合任务

实际杠杆：
投入：50个原子任务
产出：10个完整业务能力 + 40个中间流程 + 50个可复用单元
复用率：分子任务中平均每个原子任务被使用 40×3/50 = 2.4次
```

### 3.3 优化方向

**提升原子任务复用**：
- 识别高频原子任务（如文本分类、数据库查询）
- 优化通用性，降低场景耦合
- 建立原子任务库，Skills Manager统一管理

**降低分子任务复杂度**：
- 每个分子任务控制在2-5个原子任务
- 提高分子任务复用率

## 四、Coin Hour定价设计

### 4.1 定价原则

1. 原子任务：按资源消耗定价（API调用、算力）
2. 分子任务：原子任务成本总和 × 1.2倍
3. 复合任务：分子任务成本总和 × 1.5倍（含管理成本）

### 4.2 具体定价表

| 层级 | 任务示例 | Coin Hour |
|------|---------|----------|
| **原子任务** | | |
| 文本分类 | 单次分类 | 0.5 CH |
| 数据库查询 | 单次查询 | 1 CH |
| API调用 | 单次调用 | 1-5 CH |
| 图片生成 | 单张图片 | 5 CH |
| 语音合成 | 1分钟音频 | 2 CH |
| 记忆检索 | 单次检索 | 0.5 CH |
| **分子任务** | | |
| 问题分类 | 含3个原子 | 2 CH |
| 信息检索 | 含3个原子 | 5 CH |
| 内容发布 | 含3个原子 | 15 CH |
| 会议准备 | 含4个原子 | 10 CH |
| **复合任务** | | |
| 客服对话全流程 | 含4个分子 | 50-100 CH |
| 梯田导览服务 | 含5个分子 | 100-200 CH |
| 短剧制作发布 | 含4个分子 | 200-500 CH |
