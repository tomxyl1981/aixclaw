## 五、技术实现细节

### 5.1 GraphRAG整合

```
MiroFish GraphRAG → Graphify

种子提取 → Graphify图谱构建
    ↓
实体关系 → Graphify节点连接
    ↓
记忆注入 → Graphify知识存储
    ↓
预测查询 → Graphify检索
```

### 5.2 Multi-Agent整合

```
MiroFish Multi-Agent → OpenClaw

Persona生成 → Agent性格定义
    ↓
行为逻辑 → Agent Skills
    ↓
社会演化 → Ruflo编排
    ↓
ReportAgent → 一人公司Agent
```

### 5.3 记忆系统整合

```
MiroFish记忆 → AIX记忆栈

Zep Cloud → Awareness-Local（运行时）
    ↓
长期记忆 → Memvid（持久化）
    ↓
集体记忆 → EverOS（团队共享）
    ↓
知识图谱 → Graphify（结构化）
```

## 九、部署与使用

### 9.1 环境要求

| 工具 | 版本 |
|------|------|
| Node.js | 18+ |
| Python | 3.11-3.12 |
| LLM API | OpenAI兼容格式 |
| Zep Cloud | 记忆服务 |

### 9.2 快速启动

```bash
# 克隆
git clone https://github.com/666ghj/MiroFish.git

# 配置环境变量
cp .env.example .env

# 安装依赖
npm run setup:all

# 启动
npm run dev
```

### 9.3 Docker部署

```bash
docker compose up -d
```
