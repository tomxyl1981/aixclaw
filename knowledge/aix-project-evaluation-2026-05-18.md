## 2. OmniVoiceStudio ⭐ 语音核心

**GitHub**: https://github.com/depalash/OmniVoiceStudio  
**特性**: 开源ElevenLabs替代 | 646语言 | 3秒克隆

### 核心价值
- **本地运行**（数据不离开AIX Box）
- **646种语言**（覆盖那耶村方言+国际）
- **零样本克隆**（3秒音频复刻声音）
- **视频配音**（自动唇形同步）

### AIX契合点

| 场景 | 应用方式 | Coin Hour定价 |
|------|----------|---------------|
| **TutorBot语音** | 为4个导师克隆专业声音 | 20 CH/声音 |
| **那耶村文旅** | 多语言景点自动讲解 | 5 CH/景点 |
| **Skill语音输出** | 让Skill会说话 | 按使用计费 |
| **内容创作** | 短剧/播客配音生产 | 10 CH/分钟 |
| **老人关怀** | 子女声音克隆陪伴 | 50 CH/克隆 |

### 关键优势
```
AIX vs ElevenLabs:
┌────────────────┬──────────────────┬────────────────┐
│     维度       │    ElevenLabs    │ OmniVoiceStudio│
├────────────────┼──────────────────┼────────────────┤
│ 数据隐私       │ 上传云端 ❌       │ 本地运行 ✅     │
│ 成本           │ $5/月订阅        │ 一次性部署      │
│ 语言覆盖       │ 29种             │ 646种 ✅        │
│ 网络依赖       │ 需要联网         │ 离线可用 ✅     │
│ 与AIX整合      │ 难               │ 原生Skill ✅    │
└────────────────┴──────────────────┴────────────────┘
```

### 建议集成
1. **高优先级**：创建 `omni-voice` Skill
2. 集成到DeepTutor平台（TutorBot语音）
3. 那耶村MVP：多语言导游系统
4. 一人公司培训：声音资产化模块

## 3. RADIO-ViPE ⭐ 物理AI

**官网**: https://be2rlab.github.io/radio_vipe  
**底层**: https://github.com/nv-tlabs/vipe  
**定位**: 机器人具身智能 + 视觉语言模型

### 核心价值
- 机器人自主执行任务（通过自然语言指令）
- 视觉-语言-动作多模态
- NVIDIA Tesla Lab技术背书

### AIX契合点（需评估）

**场景1：那耶村智慧农业**
```
指令："检查水稻长势并浇水"
   ↓
RADIO-ViPE+VLA模型
   ↓
机器人：
- 视觉识别水稻生长状态
- 自然语言理解任务
- 控制机械臂浇水
- 记录数据到AIX Box
```

**场景2：机器间付费（关键创新）**
```
AIX Box + RADIO-ViPE:
┌─────────────────────────────────────────┐
│  机器人A（收割机）完成了任务           │
│       ↓                                 │
│  UTXO账本记录工作量 → 请求支付         │
│       ↓                                 │
│  机器人B（运输车）确认服务             │
│       ↓                                 │
│  Coin Hour自动结算（无需人类）         │
└─────────────────────────────────────────┘
```

### 挑战与风险
| 挑战 | 说明 | 应对 |
|------|------|------|
| **硬件成本** | 机器人硬件昂贵 | 那耶村申请政府农业科技补贴 |
| **技术门槛** | 需要ROS/机器人背景 | 首批只针对技术型学员 |
| **数据安全** | 机器人操作风险 | AIX Box本地控制+人工监督 |
| **成熟度** | GitHub未完全开源 | 联系作者获取合作机会 |

### 建议评估
- **短期**：观望，那耶村MVP暂停机器人场景
- **中期**：联系be2rlab寻求合作/授权
- **长期**：AIX Box作为机器人"大脑"+经济结算节点
