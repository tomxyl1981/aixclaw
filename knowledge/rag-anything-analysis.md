## 一、项目概述

**一句话**：港大DS实验室的多模态RAG一站式框架——PDF/Office/图片全格式支持，自动解析文本/图表/表格/公式，构建跨模态知识图谱。

**核心能力**：
- 多模态文档解析（PDF/Office/图片）
- 自动提取文本、图表、表格、公式
- 跨模态知识图谱构建
- 多模态查询（文本+图像混合检索）

## 三、对AIX项目的直接帮助

### 3.1 梁越作品知识库构建

| 需求 | RAG-Anything能力 |
|------|------------------|
| 梁越50万字小说解析 | ✅ PDF/DOCX解析 |
| 书中历史图表/地图提取 | ✅ 图表/表格识别 |
| 人物关系图谱 | ✅ 跨模态实体提取 |
| 时间线提取 | ✅ 结构化数据解析 |

**应用场景**：
```
《隐没的战象》PDF
        ↓ RAG-Anything
┌───────────────────────┐
│ 多模态知识库          │
│ - 人物实体库          │
│ - 时间线图谱          │
│ - 地理空间关系        │
│ - 历史事件关联         │
└───────────────────────┘
        ↓ ViMax调用
AI漫剧创作（角色/场景一致）
```

### 3.2 AI漫剧创作平台支撑

| 平台模块 | RAG-Anything作用 |
|----------|------------------|
| 剧本理解Agent | 提供知识图谱检索 |
| 角色一致性Agent | 从知识库提取角色特征 |
| 场景一致性Agent | 从知识库提取地理/历史背景 |
| Verifier Agent | 检索知识库验证内容准确性 |

### 3.3 与ViMax的协同

**同一个实验室（港大DS）**，天然协同：

| 项目 | 功能 | 协同点 |
|------|------|--------|
| **RAG-Anything** | 知识库构建 | 提供结构化知识 |
| **ViMax** | 视频生成 | 调用知识库保证一致性 |

**集成架构**：
```
梁越作品PDF → RAG-Anything → 知识图谱
                                ↓
                        ViMax Agent调用
                                ↓
                角色特征 + 场景描述 + 历史背景
                                ↓
                        一致性保证的AI漫剧
```

## 四、与AIX Box的集成

### 4.1 本地部署方案

| 组件 | 运行位置 | 说明 |
|------|----------|------|
| 文档解析 | AIX Box本地 | MinerU本地运行 |
| 向量存储 | AIX Box本地 | ChromaDB/本地向量库 |
| 知识图谱 | AIX Box本地 | 轻量级图数据库 |
| VLM推理 | AIX Box本地 | 7B多模态模型 |
| 大模型调用 | 云端溢出 | 复杂推理任务 |

### 4.2 数据主权保证

```
梁越作品PDF → 上传到AIX Box
                    ↓ 本地解析
            知识图谱存在本地存储
                    ↓
            只有本地Agent可访问
                    ↓
            数据不离开设备
```

## 五、具体应用场景

### 5.1 《隐没的战象》AI漫剧

```

Step 2: RAG-Anything解析
```
