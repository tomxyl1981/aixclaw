## 一、产品定义

| 项目 | 内容 |
|------|------|
| 品名 | **那耶云米** |
| 品类 | 大米 |
| 产地 | 云南文山富宁·那耶梯田（海拔660-1180米） |
| 规格 | 5斤/袋（2.5kg） |
| 首批产量 | 1000袋 |
| 文化背书 | 梁越"象耕鸟耘"千年梯田 |

## 二、品牌定位

**那耶云米 = 中国梯田米品类开创者**

不跟五常米拼知名度，开创"梯田米"新品类：
- 五常米 = 平原黑土
- 那耶米 = 高山梯田

### 差异化三角

```
海拔千米（地理唯一性）
千年梯田（历史厚度）
象耕鸟耘（文化IP）
```

### Slogan候选

1. "海拔千米的米"（简洁有力，制造好奇）
2. "千年梯田，一粒云米"（文化感）
3. "象耕鸟耘的味道"（梁越背书）

**推荐**：**"海拔千米的米"** — 一句话讲完差异化

## 三、定价策略

### 成本估算

| 项目 | 估算 |
|------|------|
| 大米采购 | 4-6元/斤（梯田米收购价） |
| 包装 | 3-5元/袋 |
| 物流 | 5-8元/袋（云南发全国） |
| 人工/运营 | 2元/袋 |
| **总成本** | **约25-33元/袋** |

### 定价方案

| 规格 | 人民币 | Coin Hour | CH折扣 |
|------|--------|-----------|--------|
| 5斤日常装 | **58元** | **50 CH** | ~14% |
| 5斤礼盒装 | **88元** | **75 CH** | ~15% |

**定价逻辑**：
- 58元/5斤 = 11.6元/斤，高于普通米（3-5元/斤），低于日本越光米（20-30元/斤）
- 占位"品质米"中间地带
- CH支付有折扣，但不足以套利

### 对标参考

| 品牌 | 价格/斤 | 定位 |
|------|---------|------|
| 普通东北米 | 3-5元 | 大众 |
| 五常稻花香 | 8-15元 | 品质 |
| **那耶云米** | **11.6元** | **梯田品质** |
| 日本越光米 | 20-30元 | 高端 |
| 增城丝苗米 | 12-18元 | 地域特色 |

```

    ↓

    ↓
```

## 七、溯源体系
