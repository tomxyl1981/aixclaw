### 2.1 基础经济层：农业 + AI赋能

| 模块 | 内容 | AI赋能方式 |
|------|------|-----------|
| **梯田农业** | 水稻、农产品种植 | AIX Box采集土壤/气候/产量数据 |
| **数据采集** | 真实农业数据上链 | 传感器 → AIX Box → UTXO账本 |
| **团长带货** | 本地人用真实数据帮客户把关 | AI辅助选品+溯源+信任背书 |

**核心逻辑**：
```
农田传感器 → AIX Box采集 → 真实数据上链
                              ↓
本地团长 ← 信任数据 ← 消费者下单
                              ↓
                        Coin Hour结算
```

**团长模式详解**：
- 本地人当"团长"，不是网红，是"在地信任节点"
- 用AIX Box采集的真实数据（土壤、产量、品质）为农产品背书
- 消费者信任的不是品牌，而是"看得见的数据"
- 每笔交易走Coin Hour，经济留在村里

### 2.2 增量经济层：酒店 + 活动

| 模块 | 内容 | 目标人群 |
|------|------|----------|
| **安缦式酒店** | 极简奢居，AI主题 | AI项目投资者、数字游民 |
| **音乐节** | 线上+线下同步 | 音乐人、AI音乐爱好者 |
| **电影节** | 线上+线下同步 | 影像创作者、AI视频爱好者 |

#### 安缦式酒店

- **定位**：不是农家乐，是"AI投资者的山居"
- **功能**：住宿 + AI项目展示 + 洽谈空间
- **体验**：每个房间配备AIX Box，住客可体验本地AI服务
- **定价**：部分法币 + 部分Coin Hour

#### 音乐节 & 电影节

- **线上+线下同步**：
  - 线下：那耶村实景舞台/露天影院
  - 线上：全球直播 + AI辅助翻译 + Coin Hour购票
- **AI创作赛道**：
  - 参赛者用AI工具（ViMax视频生成、AI音乐生成）创作
  - 作品上链（Avatar NFT），版权归属创作者
  - 优秀作品 Coin Hour 激励
- **经济闭环**：
  ```
  参赛者创作 → AI工具消耗Coin Hour
      ↓
  作品上链 → Avatar NFT交易
      ↓
  观众购票 → Coin Hour结算
      ↓
  优秀创作者 → Coin Hour奖励
  ```

### 2.3 杠杆经济层：AI + 投资

| 模块 | 内容 | 目标人群 |
|------|------|----------|
| **AI村** | 学习用AI做电影和音乐 | 创作者、学生、转型人群 |
| **AI创业创新大赛** | 线上+线下项目路演 | 创业者、投资者 |
| **项目展示** | 投资者来村看项目 | 天使投资人、VC |

#### AI村（AI Learning Village）

- **核心卖点**：来村里学AI做电影和音乐
- **课程体系**：
  | 课程 | 时长 | 工具 | 产出 |
  |------|------|------|------|
  | AI电影入门 | 3天 | ViMax + 剪映 | 1分钟短片 |
  | AI音乐创作 | 2天 | Suno/Udio + 本地模型 | 3首原创曲目 |
  | AI叙事工坊 | 5天 | 全流程 | 完整短片+配乐 |
  | 数字主权实践 | 1天 | AIX Box体验 | Coin Hour钱包 |
- **经济模型**：
  - 学费：法币 + Coin Hour混合
  - 住村期间：Coin Hour消费（食宿+工具）
  - 结业作品：上链NFT，Coin Hour分成

#### AI创业创新大赛

- **形式**：线上初赛 + 线下决赛（那耶村）
- **赛道**：
  | 赛道 | 主题 |
  |------|------|
  | 数字主权 | 去中心化AI应用 |
  | 乡村AI | 农业AI+社区AI |
  | AI原生内容 | AI生成的电影/音乐/艺术 |
  | 硬件创新 | 边缘AI设备 |
- **投资者吸引**：
  - 决赛在那耶村举办
  - 配套安缦式酒店住宿
  - 现场体验AIX Box + Coin Hour
  - 投资用Coin Hour完成（早期折扣）

### 全场景Coin Hour流通

```

        → 创作作品 → NFT出售 → 赚Coin Hour
```

## 十一、双轨制收益模型（2026-05-20 新增）

### 外部收益（法币入口）

**视频号创作者分成**

| 阶段 | 粉丝数 | 月收入 | 收益来源 |
|------|--------|--------|----------|
| 新手 | 100-1000 | 0-1000元 | 分成计划（0.5-12元/千次播放） |
| 中级 | 1000-10000 | 1000-10000元 | 分成 + 带货（佣金10%-30%） |
| 高级 | 10000+ | 10000元+ | 分成 + 带货 + 互选广告（1000-5000元/条） |

**关键数据**：
- 创作者分成：平台分60%，有效播放≥5秒计费
- 垂直领域（金融/美妆/知识）：8-12元/千次
- 泛娱乐：3-6元/千次
- 带货佣金：10%-30%
- 直播打赏：直接归创作者

### 内部收益（Coin Hour闭环）

**村内所有交易走Coin Hour**

| 场景 | 外部（法币） | 内部（Coin Hour） |
|------|--------------|-------------------|
| 学AI工具 | 法币学费入口 | Coin Hour购买课程 |
| 创作分成 | 平台法币收入 | 部分换Coin Hour |
| 村内消费 | 法币入口（游客） | Coin Hour结算（折扣） |
| 农产品购买 | 法币支付 | Coin Hour折扣 |
| 投资入股 | 法币入资 | Coin Hour股权凭证 |
| NFT交易 | — | Coin Hour唯一结算 |

### 双轨流转逻辑

```
外部平台（视频号/抖音/快手）
        ↓ 法币收入
    创作者账户
        ↓ 部分换Coin Hour
    Coin Hour钱包
        ↓ 村内消费
┌───────┴───────┐
│               │
AI工具费     农产品/食宿
│               │
AIX Box      村民收入
（Coin Hour） （Coin Hour）
```

### 关键设计

**法币→Coin Hour入口**：
- 外部平台收入部分兑换Coin Hour
- 兑换比例由基金会动态调整
- Coin Hour锚定1元人民币，避免波动

**Coin Hour→法币出口**：
- 原则上不开放自由兑换（防止外流）
- 仅限特定场景：大额投资退出、特殊情况提现
- 需要基金会审批

**经济闭环目标**：
```
外部赚法币 → 注入系统 → Coin Hour内循环 → 不外流
```

### 收益对比

| 类型 | 外部收益 | 内部收益 |
|------|----------|----------|
| **创作者** | 平台分成（法币） | 工具费节省（Coin Hour） |
| **村集体** | 农产品销售（法币） | Coin Hour分红 |
| **投资者** | — | Coin Hour股权增值 |
| **AIX基金会** | 投资回报（法币） | Token升值（Coin Hour产出） |
