## 二、IP Token商业模式

### 核心逻辑

```
梁越作品IP → 铸造IP Token → 出售给创作者
                                ↓
创作者购买Token → 使用AIX设备+平台创作
                                ↓
作品产出 → 多平台分发 → 收益分账
                                ↓
Token持有者分成 → Coin Hour结算
```

### IP Token设计

| 属性 | 说明 |
|------|------|
| **Token名称** | LIANG（梁越IP Token） |
| **Token类型** | IP授权凭证（NFT标准） |
| **锚定资产** | 梁越作品的改编授权 |
| **计价单位** | Coin Hour |
| **有效期** | 按作品/按时间（Token持有期间有效） |

### Token分类

| Token类型 | 授权范围 | 价格 | 适合人群 |
|-----------|----------|------|----------|
| **单集Token** | 一部作品·单集改编 | 100-500 CH | 个人创作者 |
| **系列Token** | 一部作品·全系列 | 1000-5000 CH | 工作室 |
| **全IP Token** | 梁越全部作品 | 10000-50000 CH | 影视公司 |
| **独占Token** | 特定作品独占授权 | 面议 | 大型制作方 |

### 收益分配

```
作品销售收入
    ├── 创作者：50%（二次创作劳动）
    ├── 梁越/IP Token池：20%（IP价值）
    ├── 平台：20%（设备+工具+分发）
    └── AIX基金会：10%（投资回报）

IP Token池的20%分配：
    ├── Token持有者按持有比例分红
    ├── 梁越本人基础分成（保底）
    └── Token回购销毁（通缩机制）
```
