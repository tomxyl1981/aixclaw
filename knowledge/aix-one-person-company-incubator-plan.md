# AIX Box驱动的一人公司创业孵化培训计划

> 核心理念：一个人+一套Agent=一家科技公司  
> 基础设施：AIX Box + DeepTutor培训平台  
> 经济循环：Coin Hour内部结算

---

## 📋 培训计划概览

| 维度 | 设计 |
|------|------|
| **培训对象** | 数字游民、创作者、返乡青年、小微企业主 |
| **培训周期** | 21天集中训练营 + 90天孵化期 |
| **培训方式** | DeepTutor TutorBot自主学习 + 那耶村线下驻地 |
| **基础设施** | 每人一台AIX Box + Mac mini推理中枢 |
| **经济模型** | Coin Hour消费，产出Skill上架销售 |
| **孵化目标** | 21天完成首个可售Skill，90天实现月收入>1000 CH |

---

## 🎯 培训目标

1. **技能目标**：掌握一人公司Agent技术栈（九层架构）
2. **产出目标**：每位学员完成并上架至少1个Skill
3. **收入目标**：孵化期内实现Coin Hour正循环
4. **生态目标**：孵化出的项目持续运行在AIX生态内

## 💰 经济模型设计

### 培训成本（Coin Hour）

| 项目 | 费用 |
|------|------|
| 21天训练营 | 500 CH |
| AIX Box租赁（90天） | 300 CH |
| Mac mini算力 | 200 CH |
| 导师支持 | 按服务计费 |
| **总计** | **1000 CH** |

### 收入来源

| 渠道 | 说明 |
|------|------|
| Skill销售 | 收入100%归创作者，平台抽成0% |
| 咨询服务 | 为企业定制Skill |
| 算力出租 | 闲置AIX Box算力共享 |
| 内容创作 | 教程、案例分享奖励 |

### 回本路径

```
投入：1000 CH
    ↓
21天：完成Skill开发 → 上架奖励100 CH
    ↓
30天：完成3单 → 成交奖励200 CH + 销售收入300 CH
    ↓
60天：用户增长到10人 → 里程碑500 CH + 收入600 CH
    ↓
90天：月收入稳定1000 CH → 完全回本，开始盈利
```
