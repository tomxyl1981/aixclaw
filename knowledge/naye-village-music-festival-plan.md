## 一、核心理念

**跨界跨时代视听盛宴**
```
民族音乐（壮族/苗族）+ 非遗传承 + 当地乐器
            ↓
西洋古典乐演奏形式（交响化编排）
            ↓
AI音乐系统制作赋能
            ↓
那耶村原生态自然环境呈现
```

## 二、音乐节架构

### 主题设计

| 元素 | 内容 | AI赋能方式 |
|------|------|-----------|
| **民族音乐** | 壮族/苗族传统曲目 | AI编曲（西洋交响化） |
| **非遗传承** | 当地乐器演奏实录 | AI采样 + 数字化保存 |
| **西洋形式** | 交响乐编排 | AI作曲/编曲（Suno/Udio） |
| **自然环境** | 梯田/山景/云海 | AI生成环境音效 |

### 节目编排

```
开场：云海晨曲（AI生成环境音 + 梯田实景）
      ↓
第一乐章：壮族山歌交响化（AI编曲 + 民族乐器实录）
      ↓
第二乐章：苗族芦笙与西洋管弦对话（跨界融合）
      ↓
第三乐章：非遗乐器独奏（铜鼓/葫芦丝/芦笙）
      ↓
终章：梯田交响曲（AI合成 + 全场互动）
```

## 三、AI音乐系统选择

| 工具 | 用途 | Coin Hour定价 |
|------|------|--------------|
| **Suno/Udio** | AI音乐生成 | 10-50 CH/曲目 |
| **Stable Audio** | 环境音效生成 | 5-20 CH/音效 |
| **Riffusion** | 音频风格迁移 | 20-50 CH/迁移 |
| **MusicGen** | 本地音乐生成（AIX Box） | 免费（本地算力） |

### 推荐技术栈

```
Phase 1：云端AI生成（快速验证）
  ├── Suno：壮族山歌交响化编曲
  ├── Udio：苗族芦笙跨界融合
  └── Stable Audio：环境音效

Phase 2：本地AI生成（数据主权）
  ├── MusicGen（AIX Box内置）
  ├── Riffusion（风格迁移）
  └── 本地采样库（非遗乐器数字化）

Phase 3：实时交互演出
  ├── AI伴奏系统（实时生成）
  ├── 观众互动音乐（手机参与）
  └── Coin Hour实时结算
```
