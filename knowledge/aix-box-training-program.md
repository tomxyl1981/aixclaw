**Day 4 实操脚本：**
```bash
# 1. 激活AIX Box
aix-box activate --device-id BOX-001

# 2. 连接Pico Claw推理中枢
pico-claw connect --host m4-mini.local --port 8080

# 3. 验证连接
aix-box status
# 预期输出：
# ✅ Box已激活
# ✅ Pico Claw连接正常
# ✅ UTXO账本同步中
# ✅ 存储空间：1TB可用
```
