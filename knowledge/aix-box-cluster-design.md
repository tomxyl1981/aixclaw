# AIX Box 完美集群设计方案

> 设计目标：从个人AI助手进化成边缘云计算网络
> 设计原则：乐高式物理扩展 + 细胞式网络自治 + 水电式服务计费

---

## 一、物理层：卡扣标准 + 功能模块

### AIX-Connector v1.0 卡扣接口

```
物理规格：
  - 磁吸+卡扣双固定（易拆但牢固）
  - 触点：电源共享 + 数据总线（PCIe 4.0 x4） + 同步时钟
  - 最大串联：8个Box（电源和数据带宽限制）
  - 防呆设计：方向错误无法插入
```

### 六大功能模块

| 模块 | 核心配置 | 适用场景 | 价格预估 |
|------|----------|----------|----------|
| **Core** | J1900 + 4GB + 500GB | 入门节点、轻量Agent | ¥4000 |
| **Brain** | RK3588 + 8GB + 1TB | 中等推理、多Agent调度 | ¥6000 |
| **Power** | M4/M4 Pro + 64GB | 大模型推理、复杂计算 | ¥12000 |
| **Vault** | 4TB NVMe + 加密芯片 | 数据存储、备份节点 | ¥5000 |
| **Link** | 5G + WiFi6 + 卫星模块 | 偏远地区、移动场景 | ¥3000 |
| **Safe** | HSM 2.0 + 生物识别 | 高安全需求、金融场景 | ¥4000 |

### 热管理与电源

```
散热设计：
  - 纵向叠加：热风向上排出，不互相加热
  - 被动散热+低转速风扇（静音，<25dB）
  - 可选外置散热底座（高负载场景）

电源设计：
  - 单Box：PD 100W USB-C
  - 集群：300W GaN充电器（一拖四）
  - Vault模块标配UPS断电保护
```

## 二、集群拓扑：三种组网模式

### 模式1：星型主从（那耶村模式）

```
[Power主控Box] ←→ 账本同步、任务调度
      │
      ├── [Core终端1] 村民A使用
      ├── [Core终端2] 村民B使用  
      ├── [Core终端3] 游客服务
      └── [Vault存储] 全村数据备份

特点：
  - 1个Power+M4负责重推理
  - N个Core负责轻交互
  - Vault确保数据冗余
  - 总成本：~3万，服务50-100人
```

### 模式2：对等网格（社区自治模式）

```
[Box A: Core+Link] ←→ [Box B: Brain+Vault]
      ↕                    ↕
[Box C: Power] ←→ [Box D: Core+Safe]

特点：
  - 无主节点，分布式共识（Raft/PBFT）
  - 任意节点掉线不影响整体
  - 算力/存储共享，Coin Hour按贡献分配
  - 适合：数字游民社区、DAO组织
```

### 模式3：混合分层（商业服务模式）

```
Layer 3: 接入层（10-100个Core Box）
         └── 终端用户直接接触

Layer 2: 服务层（5-10个Brain Box）
         └── Agent调度、负载均衡

Layer 1: 核心层（2-3个Power Box + Safe）
         └── 大模型推理、关键数据、账本共识

Layer 0: 存储层（Vault Box集群）
         └── 分布式存储、跨地域备份

特点：
  - 可扩展至数百节点
  - 对外提供API服务（按Coin Hour计费）
  - 类似"微型AWS"，但完全去中心化
```

## 三、服务架构：自用 + 商用一体化

### 自用能力（个人/家庭）

| Stack组合 | 能力 | 适用场景 |
|-----------|------|----------|
| **基础** (Core) | 个人助手、文档存储、基础RAG | 个人用户入门 |
| **增强** (Core+Brain) | 视频生成、多Agent协作、离线地图 | 家庭使用 |
| **专业** (Core+Brain+Power) | 代码开发、视频渲染、复杂分析 | 专业用户 |

### 商用能力（对外服务）

```
服务发现：
  - Box自动广播能力（Bonjour/Skywire）
  - 邻居发现：附近Box自动组网

服务提供：
  - 算力出租：Power Box空闲时对外推理
  - 存储出租：Vault Box提供备份空间
  - 网络中继：Link Box作为 mesh 节点
  - 安全认证：Safe Box提供签名服务

计费模式：
  - 按次：单次API调用（X Coin Hour）
  - 按时：按小时租赁算力（X Coin Hour/小时）
  - 按量：存储空间租赁（X Coin Hour/GB/月）
```

## 四、那耶村MVP集群配置

### 集群总览

```
位置：那耶村文化活动中心
节点数：1主控 + 6终端 + 2备用 = 9个Box
服务对象：村民50户 + 游客日均20人
总成本：约¥6-8万（含主控集群和村民补贴）
```

### 节点配置

**主控节点（1个）**
- 组合：Power Box + Link Box
- 配置：M4 Pro 64GB + 2TB + 5G/卫星模块
- 职责：大模型推理、全村账本、对外出口、Coin Hour结算

**服务节点（3个）**
- 配置：Brain Box (RK3588 + 8GB + 1TB)
- 位置：村头、村委会、民宿
- 职责：日常AI服务、数据缓存、轻量推理、多语言服务

**终端节点（3个）**
- 配置：Core Box (J1900 + 4GB + 500GB)
- 位置：村民家中（试点）
- 职责：个人数据存储、家庭AI助手、Coin Hour产出

**存储节点（2个）**
- 配置：Vault Box (8TB RAID1)
- 位置：村委会（主）、村民家（备）
- 职责：全村数据备份、游客内容存储、企业备份服务

### 服务场景

**村民日常使用**
- 健康咨询 → Brain节点 → 必要时转Power节点深度分析
- 农产品信息 → Brain节点本地RAG
- 娱乐内容 → Core节点本地存储的视频/音乐

**游客服务**
- 导览问答 → Brain节点多语言服务
- 照片备份 → Vault节点临时存储
- 支付结算 → 主控节点Coin Hour处理

**对外商业**
- 云端算力：Power节点空闲时对外出租
- 数据归档：Vault节点提供企业备份服务
- 内容分发：Link节点作为CDN边缘节点

### 经济模型

```
村民投入：
  - 主控集群：村集体出资（¥4万）
  - 终端Box：村民自愿购买（¥4000/台，内含AIX权益）
  
收益分配：
  - 对外服务收入 → 30%归节点所有者，70%归村集体Coin Hour池
  - 村民使用 → 消耗个人Coin Hour（持有AIX产出）
  
回本周期：
  - 终端Box：自用+对外服务，预计6-12个月回本
```

```
自动发现：
  - 新Box接入自动识别角色

资源调度：
```

## 六、关键设计决策

### 为什么选择模块化而不是一体机？

| 维度 | 模块化集群 | 一体机 |
|------|------------|--------|
| 扩展性 | 按需添加模块 | 固定配置 |
| 成本 | 渐进投入 | 一次性高额 |
| 故障隔离 | 单模块故障不影响整体 | 整机宕机 |
| 升级 | 单独更换模块 | 整机更换 |
| 社区共建 | 村民可参与（买终端Box） | 完全中心化管理 |

### 卡扣vs线缆连接？

```
卡扣优势：
  - 即插即用，无需技术背景
  - 物理可视化（村民看到集群壮大）
  - 移动方便（临时活动可拆卸重组）
  
线缆劣势：
  - 需要布线知识
  - 杂乱不美观
  - 接触不良风险
```
