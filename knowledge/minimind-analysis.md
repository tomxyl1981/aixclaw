## 一、项目概述

**核心能力**：2小时从零训练64M参数的LLM，成本仅3元

**关键数据**：

| 指标 | 数值 |
|------|------|
| 模型参数 | 64M（MiniMind-3）/ 198M MoE |
| 训练时间 | 2小时（单张3090） |
| 训练成本 | ¥3 |
| 体积 | GPT-3的1/2700 |
| 硬件需求 | 单张NVIDIA 3090 |
| 内存占用 | ~0.5GB |

---

## 二、核心特性

### 2.1 完整训练流水线

```
Tokenizer → Pretrain → SFT → LoRA → DPO → PPO/GRPO → Agentic RL
```

### 2.2 纯PyTorch原生实现

- 不依赖第三方库（transformers、peft等）
- 代码透明，无黑箱
- 适合学习和定制

### 2.3 多种训练方式

| 方式 | 说明 |
|------|------|
| 预训练 | 从零学习知识 |
| SFT | 指令微调 |
| LoRA | 低秩适应 |
| DPO | 直接偏好优化 |
| RLAIF | PPO/GRPO/SPO |
| Agentic RL | 多轮工具调用 |
| 模型蒸馏 | 领域适应 |

### 2.4 多模态支持

- MiniMind-V：视觉多模态扩展
- 图像+文本处理

### 2.5 兼容性

- ✅ llama.cpp
- ✅ vLLM
- ✅ Ollama
- ✅ SGLang
- ✅ OpenAI API协议
- ✅ FastGPT, Open-WebUI, Dify

## 六、对AIX项目的帮助

### 6.1 AIX Box本地推理

**问题**：AIX Box需要本地推理能力，但大模型资源需求高

**MiniMind解决方案**：
- 64M参数模型可部署在边缘设备
- 内存仅0.5GB，适合AIX Box
- 支持Ollama，可直接集成

### 6.2 训练那耶村专属模型

**场景**：用那耶村语料训练专属模型

```

├── 梁越作品（《隐没的战象》等50万字）
├── 那耶村历史资料
├── 壮族/苗族文化资料
├── 农业知识
└── 本地方言

训练成本：
├── 单张3090（或Mac M4）
├── 2-3小时
├── ¥3-5
```

**产出**：
- 那耶村文化专属LLM
- 可用于：游客问答、文化讲解、创作辅助

## 七、集成方案

### 7.1 技术架构

```
那耶村AI系统：
├── 推理中枢：Mac mini M4（7B-13B模型）
├── 边缘节点：AIX Box（MiniMind 64M模型）
└── 云端溢出：DeepSeek API（复杂任务）

分工：
├── 简单任务（本地问答）→ MiniMind on AIX Box
├── 中等任务（创作辅助）→ 7B on Mac mini
└── 复杂任务（推理分析）→ DeepSeek API
```

### 7.2 数据流

```
用户请求 → AIX Claw路由
              ↓
         任务复杂度判断
              ↓
    ┌─────────┼─────────┐
    ↓         ↓         ↓
 MiniMind   7B模型   云端API
 (本地)    (本地)    (溢出)
```
