### 核心功能

**一体化多模态RAG框架**：
- 📄 文档解析：PDF、Office、图片等通用格式
- 🧠 内容分析：图片、表格、公式、图表专用处理器
- 🔗 知识图谱：自动实体提取 + 跨模态关系发现
- 🔍 智能检索：文本+多模态混合检索
- 🤖 多模态查询：文本+图片+表格+公式联合问答

### 技术架构

```
文档输入 → MinerU解析 → 内容分解 → 并行处理管道
                                            ↓
                              ┌─────────────────────┐
                              │ 文本管道  │
                              │ 视觉管道  │
                              │ 表格管道            │
                              │ 公式管道            │
                              └─────────────────────┘
                                            ↓
                              多模态知识图谱构建
                                            ↓
                              混合智能检索 + 问答生成
```

- 多模态处理需要VLM（视觉语言模型）

- 需要MinerU文档解析器

- 评估：部署成本较高，但一旦完成价值很大

#### 3. 与现有架构的整合
- AIX九层架构第零层（记忆层）已有Graphify等方案

### 🚀 核心特性

#### 1. 极致性能优化（碾压级）

**内存对比（10个session）**：
| 工具 | RAM | 对比 |
|------|-----|------|
| **jcode** | 260 MB | 基准 |
| Claude Code | 2300 MB | **19.7×** |
| OpenCode | 3237 MB | **27.7×** |
| Cursor Agent | 1632 MB | **14×** |

**启动速度**：
| 工具 | 时间 | 对比 |
|------|------|------|
| **jcode** | 14 ms | 基准 |
| Claude Code | 3437 ms | **245×慢** |
| OpenCode | 1036 ms | **74×慢** |

**关键**：用Rust重写，专为多session场景优化

---

#### 2. Agent Memory系统（类人记忆）

```
对话 → 向量嵌入 → 记忆图谱 → 相似性检索 → 自动注入上下文
```

- 每轮对话自动向量化存入记忆图谱
- 相似话题自动召回（不需要显式调用memory工具）
- 记忆提取 → 验证 → 整合 → 冲突检测
- 跨session搜索（RAG式）

**与AIX第零层记忆设计高度吻合**

---

#### 3. Swarm多Agent协作

```
spawn多个agent → 同repo协作 → 冲突自动检测 → 消息传递 → 任务分配
```

- Agent A编辑文件 → Agent B收到通知 → 自动检查冲突
- 主agent变成coordinator → spawned agents变成workers
- 支持headless/headed模式

**与AIX第四层组件层设计方向一致**

---

#### 4. Self-Dev模式（自修改）

```
进入self-dev → 修改自己的源码 → 构建 → 测试 → reload binary → 继续工作
```

- Agent可以修改jcode本身
- 自动构建、测试、reload
- 真正的"自演化"

**与AIX自演化框架理念高度一致**

---

#### 5. MCP支持 + 动态Skills

```json
{
  "servers": {
    "filesystem": {"command": "npx", "args": ["@anthropic/mcp-server-filesystem"]},
    "github": {"command": "npx", "args": ["@anthropic/mcp-server-github"]}
  }
}
```

- Agent可以动态添加MCP server
- Skills热加载（无需重启）
- 工具动态注册/注销

**与AIX技能层+插件层设计完全吻合**

---

#### 6. 多Provider支持

- Claude / OpenAI / Gemini / Copilot
- DeepSeek / 阿里云编码计划 / 火山引擎 / Minimax
- Ollama / LM Studio / vLLM本地
- 自定义OpenAI兼容endpoint

**关键：支持国产模型+本地部署**

### Codex /goal 源码解析（2026-05-17）

**来源**：用户377861 分享
