## 腾讯CubeSandbox：AI Agent安全沙箱（5.6K星）

**GitHub**: https://github.com/TencentCloud/CubeSandbox  
**Stars**: 5,645  
**语言**: Rust  
**协议**: Apache 2.0  
**定位**: 即时、并发、安全的AI Agent沙箱服务

### 核心参数

| 指标 | Docker | 传统VM | CubeSandbox |
|------|--------|--------|-------------|
| 隔离级别 | 低（共享内核） | 高（独立内核） | **极高（独立内核+eBPF）** |
| 冷启动 | 200ms | 秒级 | **<60ms** |
| 内存开销 | 低 | 高 | **<5MB** |
| 部署密度 | 高 | 低 | **极高（单节点数千个）** |
| E2B兼容 | ❌ | ❌ | **✅ Drop-in替换** |

### 架构组件

| 组件 | 职责 |
|------|------|
| CubeAPI | 高并发REST网关（Rust），E2B兼容 |
| CubeMaster | 集群编排器 |
| CubeProxy | 反向代理，E2B协议 |
| Cubelet | 计算节点本地调度 |
| CubeVS | eBPF虚拟交换机，内核级网络隔离 |
| CubeHypervisor+CubeShim | KVM MicroVM虚拟化层 |

### 对AIX的关键价值

**1. Agent安全执行环境**
- 每个Agent独立内核 → 彻底防容器逃逸
- LLM生成的代码安全执行 → Harness物理层

**2. 与AIX Box的天然组合**
```
AIX Box = 硬件钱包 + 分布式存储 + 本地推理
CubeSandbox = Agent安全执行环境
→ Box上的每个Agent在独立沙箱运行
```

**3. E2B兼容 = 零成本迁移**
- 已有E2B SDK代码 → 改一个URL → 迁移到CubeSandbox
- 不锁定闭源平台

**4. 高密度部署 = 园区效率**
- 单节点运行数千个Agent沙箱
- 那耶村/AIX园区的算力效率最大化

### 与AIX技术栈的映射

```
AIX技术栈第四层：Agent运行时层
    ↓
OpenClaw（Agent调度）
    ↓
CubeSandbox（安全执行沙箱）← 新增
    ↓
KVM MicroVM（硬件级隔离）
    ↓
AIX Box（物理节点）
```

### 硬件要求

- x86_64 Linux + KVM支持
- 支持WSL 2 / 物理机 / 云裸金属 / 普通云VM（PVM）
- ⚠️ AIX Box（ARM）暂不直接支持，需适配

### 与OpenClaw集成
