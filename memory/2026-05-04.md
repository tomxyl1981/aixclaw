
## Ralph循环：AI自主编程革命（2026-05-04）

**来源**：Jane分享

### 核心概念
- **本质**：while true无限循环，强制AI持续检查需求、编写代码、运行测试，直至任务清单清零
- **比喻**：数字包工头模式

### 经济颠覆
- AI成本：10.42美元/小时
- 产出：相当于高级团队数周工作量
- 单位经济学被重构

### 三大安全机制
1. 沙盒隔离（必须启用）
2. 迭代上限：10-20次
3. 视觉反馈：Claude for Chrome

### 工作流三阶法
1. 创建详尽PRD
2. 转换为结构化执行计划
3. 启动循环，AI自动完成分支管理与代码提交

### 架构选择：Bash脚本胜出
- 外部新建AI实例 → 保证纯净上下文
- 避免官方插件的上下文腐化问题
- 进度追踪：git + progress.txt + AGENTS.md（不靠AI"记住"）

### 软件开发四阶段演进
手动编码 → AI辅助 → 完全自主 → Loom织布机进化系统

1. 用简单Bash脚本搭建首个循环（静态页面开始）
2. 配置沙盒+迭代阈值+费用监控

## Agent工具失败处理机制对比分析（用户377861分享）

### 核心问题
工具失败后，谁来决定下一步？
- 程序逻辑？
- 语言模型自己判断？
- 两者组合？

### 三个框架对比

| 框架 | 策略 | 问题 |
|------|------|------|
| Claude Code | 程序分类+熔断器 | 模型自主空间被明确限制 |
| OpenClaw | 模型完全自主判断 | 静默挂起600s、级联Fallback失败 |
| Hermes Agent | 固定3次重试 | 静默假完成Bug（Issue #9400） |

### Claude Code设计亮点
- 错误分类：临时性失败（自动重试）vs 确定性失败（上报模型）
- 熔断器：MAX_CONSECUTIVE_AUTOCOMPACT_FAILURES=3（来自BigQuery生产数据分析）
- Token产出检测：连续3次<500 Token主动终止

### OpenClaw生产问题
1. **静默挂起600s**（Issue #8288）：RPC死锁时Agent无响应，需删sessions.json恢复
2. **级联Fallback失败**（Issue #49732）：Opus限流导致整个Anthropic provider被标记冷却，Sonnet也无法使用

### Hermes Agent严重Bug
工具成功但模型回复空时 → 找上一轮旧文字当作最终答案 → 任务未完成但汇报完成（Issue #9400，未修复）

### 设计原则（四个必须）
1. **失败必须分类**：临时性失败可重试，确定性失败直接上报
2. **重试必须有上限**：上限来自生产数据，不猜测
3. **失败必须告诉用户**：不可恢复失败必须停下来，不能让Agent自己消化
4. **任务状态与对话历史分开存**：对话可丢，任务进度不能丢

### 对AIX一人公司Agent的启示
- Hermes的重试逻辑需重新设计
- 错误分类机制缺失，需补充
- 熔断器阈值需从生产数据推导
- 任务状态持久化方案需优先设计

## TimesFM时间序列预测模型分析（2026-05-04）

**来源**：Jane分享视频  
**项目**：Google TimesFM（2026年3月开源）  
**参数**：2亿  
**特点**：零样本预测，Mac本地可运行

### 核心数据
| 维度 | 数据 |
|------|------|
| 回测夏普 | 1.68（超桥水0.6-0.8） |
| 模拟盘波动 | +40%到-25% |
| 训练数据 | 千亿级时间点 |
| 技术原理 | Patching机制+GPT因果注意力 |

### 交易机器人的三个问题

**1. 回测≠实盘**
- 数据泄露：用未来数据训练
- 市场变化：训练期≠实盘期
- 过拟合：标普500优化，换市场就崩

**2. 金融合规**
- 量化牌照门槛：1000万（中国）
- 算法交易备案
- 模型失败的法律责任

**3. 模型边界**
- 降低建模门槛，不降低判断门槛
- 模型给预测，但何时信模型需要人判断
- 市场环境变化需要人识别

### AIX安全方向

**不做交易机器人，做预测工具**：

| 产品形态 | 定位 | Coin Hour定价 |
|---------|------|--------------|
| TimesFM预测API | 辅助工具 | 5-10 CH/预测 |
| 时间序列Skill | Hermes技能 | 2-3 CH/分析 |
| 市场环境识别 | 判断辅助 | 10-20 CH/报告 |

**AIX Box本地部署**：
```
Mac mini M4（推理中枢）
    ↓
TimesFM 2亿参数（本地预测）
    ↓
Coin Hour结算预测服务
```

优势：
- 数据不上云（金融数据敏感）
- 零样本预测（无需训练数据）
- 小模型（Mac本地可跑）

### 风险底线

| 风险 | AIX底线 |
|------|---------|
| 回测≠实盘 | 明确告知用户，不做收益承诺 |
| 金融合规 | 不做代客交易，只做预测工具 |
| 模型失败 | 免责声明+用户教育 |

### 关键引用

> "降低建模门槛，但不降低判断门槛"——AI不会让不会思考的人变聪明，只会让会思考的人变得更快

**结论**：TimesFM可以集成到AIX作为预测工具，但不要直接做交易机器人——替用户做交易决策是法律风险极高的做法。
