## 💰 Coin Hour算法稳定币机制

> 来源：PDF文档

### 基本设定

| 属性 | 规则 |
|------|------|
| 自动铸造 | 每小时自动生成1个Coin Hour |
| 转账规则 | 转账销毁50%，发送方和接收方各得25% |
| 锚定目标 | 1 Coin Hour = 1 人民币 |
| AMM公式 | X × Y = 1（X=AIX价格，Y=CH兑换比例） |
| 使用范围 | 仅限AIX生态内消费，不可套现法币 |

### 价格稳定机制

#### TWAP防操纵
- 兑换价格基于24小时时间加权平均价
- 防止瞬时拉盘套利

#### 交易控制
- 单地址每小时上限3万CH
- 日超10万延迟24小时执行
- 大额兑换（>1万CH）征收5%税
- AIX价格1小时波动>20%触发熔断

### 兑换关系

```
1 AIX（价值X元）= X 个 Coin Hour

示例：
├─ AIX=1元 → 1 AIX兑换1 CH
├─ AIX=2元 → 1 AIX兑换2 CH
└─ AIX=0.5元 → 1 AIX兑换0.5 CH

结果：无论AIX价格波动，1 CH始终价值1元人民币
```
