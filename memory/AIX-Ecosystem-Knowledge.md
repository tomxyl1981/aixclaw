## 一、核心理念

### "此 Token 非彼 Token"

| 类型 | 比特币 Token | AI Token |
|------|-------------|----------|
| 本质 | 账本中的原生资产 | 模型中的工作量刻度 |
| 解决问题 | "谁有权定义历史" | "谁能更高效地产出智能" |
| 时代主题 | 货币的协议化 | 认知的工业化 |

**AIX 的愿景**：融合两种文明，让价值网络与智能网络在同一个生态中运行。

---

## 二、双代币模型

### AIX 代币
- **定位**：价值存储/交易
- **性质**：Stateful（有状态）
- **用途**：所有权、转移、验证
- **总量**：1000亿
- **上市**：LBank交易所

### Coin Hour (CH)
- **定位**：服务支付
- **性质**：Procedural（过程性）
- **锚定**：1 CH = 1 人民币
- **生成**：持有1 AIX，每小时生成1 CH
- **销毁**：转账时销毁50%
- **用途**：存储、计算、带宽费用

---

## 三、技术架构

### 底层链
- **AIX 链**：Skycoin 平行链，UTXO 模型
- **共识机制**：Obelisk + AuxPoW（与比特币联合挖矿）
- **交易速度**：300 TPS，确认时间 <2秒
- **手续费**：通过 CH 支付，近乎零成本

### 合作伙伴
- **Skycoin**：Skywire 去中心化网络
- **Emercoin**：EmerDNS 去中心化域名，NVS 存储
- **BPFS**：去中心化文件存储

## 四、核心产品（技术就绪）

### 1. AIX 超级钱包
- **定位**：生态入口
- **功能**：多钱包管理、实时行情、NFT收藏、安全中心
- **技术栈**：React Native + Expo + tRPC
- **平台**：iOS / Android / Web
- **多语言**：中文、英文、俄语、哈萨克语

### 2. AIX Exchange
- **定位**：去中心化交易平台
- **机制**：AMM (CPMM: x * y = k)
- **交易对**：AIX ⇄ Coin Hour
- **手续费**：0.3%（70%给LP，30%进储备池）
- **风控**：TWAP预言机、交易限额、熔断机制
- **技术栈**：React 19 + tRPC 11 + MySQL/TiDB

### 3. AIX P2P 拼车平台
- **定位**：去中心化网约车
- **核心优势**：平台抽佣 3-5%（vs Uber 20-30%）
- **功能**：智能拼单、动态定价、信用评分、AI客服
- **技术栈**：React 19 + Node.js 22 + tRPC
- **状态**：20+功能模块已开发完成

### 4. 华夏瑰宝捐助APP
- **定位**：嵌入超级钱包的公益捐款应用
- **流程**：捐款 → 运营单位代收 → 100%进基金会 → 生成证书 → 发放AIX奖励
- **技术栈**：React 19 + tRPC + Drizzle ORM
- **状态**：已完成
- **项目地址**：kindshipapp-5apvtvw7.manus.space

## 六、关键技术细节

### 安全机制
- AuxPoW：与比特币联合挖矿，51%攻击几乎不可能
- 图灵不完备：无智能合约漏洞风险
- 硬件钱包：物理按键确认签名

### 风控系统（Exchange）
- TWAP预言机：24小时时间加权平均价
- 交易限额：防止大额操纵
- 大额交易税：>1万CH征5%
- 熔断机制：异常波动暂停交易

### 稳定币机制
- 每小时自动铸造：每用户账户 +1 CH
- 转账销毁50%：控制通胀
- 储备池：动态调节
