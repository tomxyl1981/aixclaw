### 技术架构

```
Input → [Prelude] → [Recurrent Block × N] → [Coda] → Output
```

**关键特性**:

```
传统大模型: 固定计算量，无论任务简单或复杂
OpenMythos: 简单任务→少循环，复杂任务→多循环
              ↓
AIX Box: 节省算力=节省Coin Hour=更经济
```

**2. 分层部署策略**
| 任务复杂度 | 循环次数 | 适用场景 | AIX Box功耗 |

| 深度推理 | 5-8次 | 复杂分析 | 高 |

**3. 与Hindsight记忆结合**
```
OpenMythos推理
    ↓
Hindsight记忆检索 (相关历史)
    ↓
动态调整循环深度 (有相关记忆→减少循环)
    ↓
更快响应 + 更低CH消耗
```

- 学生问数学题 → 3-4次循环详细解释
