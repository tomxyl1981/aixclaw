## 📄 AIX Box 记忆主权方案

**文档**: `tangbite/aixbox-plans/aix-box-memory-sovereignty.md`

**背景**: Anthropic 将记忆锁进 API，LangChain 创始人批评"剥夺记忆主权"

### 核心方案

**设计原则**:
- 本地优先（NVMe SSD 存储）
- 硬件加密（ATECC608B）
- 用户可控（随时导出/迁移）
- 去中心化备份（BPFS）

**记忆分层**:
| 类型 | 生命周期 | 存储 |
|-----|---------|-----|
| 工作记忆 | 会话内 | RAM |
| 短期记忆 | 7-30天 | 本地 SSD |
| 长期记忆 | 永久 | SSD + BPFS |
| 语义记忆 | 永久 | 向量数据库 |

**技术栈**:
- 向量数据库: Chroma
- Embedding: all-MiniLM (本地)
- 加密: AES-256-GCM
- 硬件密钥: ATECC608B

### 差异化价值

> **"你的记忆，你的硬件，你的主权"**

| 维度 | Anthropic | AIX Box |
|-----|----------|---------|
| 存储 | 云端 | 本地硬件 |
| 控制 | 服务商 | 用户 |
| 迁移 | 锁定 | 开放标准 |

## 🔐 钱包即身份设计

**核心概念**: 每个 Box 内置钱包 = 用户 DID (去中心化身份)

### 身份三层功能

| 功能层 | 说明 |
|-------|-----|
| **钱包功能** | AIX 存储、Coin Hour 管理、交易签名 |
| **身份功能** | 知识图谱绑定、Skill 创作者验证、跨 Box 认证 |
| **主权功能** | 加密密钥派生、数据签名、授权管理 |

### 关键设计

```
钱包地址 → DID (did:aix:0x...)
   ↓
知识图谱实体绑定 (ownerDID)
   ↓
数据签名防篡改
   ↓
跨 Box 身份同步 (助记词恢复)
```

### 数据授权示例

- 授权 App 访问特定数据 (时间限制)
- 授权其他用户只读权限
- 随时撤销授权

**技术**: ATECC608B 硬件保护私钥

## 📄 AIX Box + Harness Design 整合方案

**文档**: `tangbite/aixbox-plans/aix-box-harness-design.md`

### 核心概念

将 Anthropic 的 Harness Design（AI 质量评估 + 审美注入）整合进 AIX Box：

| Anthropic 方案 | AIX Box 改进 |
|---------------|-------------|
| 云端运行 | 本地运行 (数据主权) |
| 中心化配置 | 每个 Box 独立 Taste Profile |
| 云端记忆 | 本地 Knowledge Graph |
| 无法共享 | Skill 市场交易 Taste Profile |

### AIX Box Harness 架构

```
Layer 4: Taste Profile (审美配置)
  └── 语气、风格、价值观、禁忌词

Layer 3: Evaluators (评估器)
  └── 准确性、流畅度、审美匹配度、安全

Layer 2: Feedback Loop (反馈循环)
  └── 显式反馈 + 隐式反馈 + 自动评分

Layer 1: Local Optimizer (本地优化)
  └── Prompt 优化、LoRA 微调、RAG 增强
```

### 关键创新

1. **Taste Profile 绑定 DID** - 可迁移、可交易
2. **基于 KG 的准确性评估** - 验证输出 vs 记忆中事实
3. **长期审美学习** - 基于 Knowledge Graph 反馈自动优化
4. **审美声誉系统** - 优质 Taste Profile 可变现

### 应用场景

- **企业**: 律师事务所的标准化文档风格
- **个人**: 作家的创意写作风格
- **Skill 市场**: 出售专业领域 Taste Profile
