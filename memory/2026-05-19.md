## 那耶村经济发展策略（2026-05-19）

**Jane提出核心思路**：那耶村要做"AI村"，吸引人来学AI做电影和音乐。

### 三层经济架构

| 层级 | 内容 |
|------|------|
| **基础经济** | 农业 + AIX Box数据采集 + 团长带货 |
| **增量经济** | 安缦式酒店 + 音乐节 + 电影节（线上+线下） |
| **杠杆经济** | AI村（学AI创作）+ AI创业大赛 + 项目路演 |

### 四类人群

1. **创作者**（学生/转型人群）：来学AI做电影音乐
2. **投资者**（VC/天使）：住酒店看项目，用Coin Hour投资
3. **消费者**（城市中产）：买溯源农产品
4. **本地村民**：团长/服务岗位，赚取Coin Hour

### 关键创新

- **团长模式**：本地人用AIX Box采集的真实数据帮客户把关带货
- **线上+线下同步**：音乐节/电影节/创业大赛全部双轨运行
- **Coin Hour闭环**：村内70%交易走Coin Hour，经济留在村里
- **本地人保障**：团长优先权、土地入股、Coin Hour分红

## 双轨制收益模型（2026-05-20 00:34 UTC）

**Jane明确**：外部收益赚法币，内部收益是Coin Hour。

### 外部收益（视频号）
- 新手：0-1000元/月（分成计划）
- 中级：1000-10000元/月（分成+带货）
- 高级：10000元+/月（分成+带货+互选广告）

### 双轨流转
```
外部平台赚法币 → 部分换Coin Hour → 村内消费 → 不外流
```

### 关键设计
- 法币→Coin Hour：自由兑换（入口开放）
- Coin Hour→法币：限制兑换（出口控制）
- 目标：法币进来，Coin Hour留在村里循环
