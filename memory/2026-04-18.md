## 📄 Coin Hour算法稳定币机制设计

**原文档**：AIX Coinhour算法稳定币机制设计.pdf  
**存档**：knowledge/aix-coinhour-design.pdf

### 核心设定

| 参数 | 值 |
|------|-----|
| 锚定 | 1人民币 |
| 铸造 | 每小时自动生成1个Coin Hour |
| 转账销毁 | 50%（发送方25%+接收方25%） |
| 套现 | 不可，智能合约禁止转出生态 |
| 用途 | 生态内消费（服务、商品、订阅、NFT） |

### 价格稳定四层机制

1. **套利机制**
   - 低于1元：Coin Hour兑换AIX→卖AIX获利→推高CH
   - 高于1元：AIX兑换Coin Hour→消费或卖出→压低CH

2. **TWAP防操纵**
   - 兑换价格基于24小时AIX时间加权平均价
   - 短时拉盘对TWAP影响极小（1小时拉到1.5元，TWAP仅升至1.02元）
   - 操纵需持续24小时推高，成本远超收益

3. **交易限制**
   - 单地址每小时兑换上限3万
   - 日累计超10万延迟24小时执行
   - 大额兑换（>1万）征5%税进储备池

4. **熔断机制**
   - AIX价格1小时内波动超20%，暂停Coin Hour兑换

### 抵押机制

- 储备池：AIX作为抵押，支撑Coin Hour 50%价值
- 另外50%由算法维持
- 动态调整：低于1元释放AIX买入，高于1元出售补充

### 消费激励

- Coin Hour高于1元时，用1元AIX兑换=折扣效应
- 生态内支付额外折扣（如10%）
- 目的：增加转账频率→放大50%销毁效果

### 风险应对

| 风险 | 应对 |
|------|------|
| 买盘不足 | LP奖励+抵押池最终买盘 |
| 大资金操纵 | TWAP+限额+交易税+熔断 |
| 挤兑 | 抵押池+DAO治理基金回购+公开数据 |
| 51%攻击 | 多源预言机+监控异常行为 |

### 与硬件定价逻辑的关联

- "1万设备内含1万AIX"中的AIX价值 = Coin Hour兑换锚定基础
- 自动铸造=持续产出=持有AIX Box的被动收入逻辑
- 不可套现=内循环闭环，价值锁定在生态内

## 📊 AIX Box完整经济闭环（2026-04-18梳理）

### 一、买入环节
- 硬件成本：≈4000人民币
- 售价：≈1万人民币
- 内含权益：≈1万AIX
- 硬件利润：≈6000人民币/台

### 二、赚钱环节（三重收入）
1. 囤AIX产出Coin Hour：每小时1个，锚定1元，24元/天
2. 分布式存储收益：Box作为存储节点赚租金
3. 自动点击广告收益：广告观看/点击收入

### 三、消费环节
1. 本地AI推理：用Coin Hour免费（前提持有AIX）
2. 那耶村生活：吃喝拉撒用Coin Hour

### 四、代币逻辑
- AIX：增值资产，波动价格，LBANK/Bitmart已上线
- Coin Hour：算法稳定币，锚定1元人民币
- 持有AIX三重价值：资本增值 + 稳定产出 + 使用权
- 交易关系：Coin Hour/AIX算法X×Y=1

### 五、闭环逻辑
买Box → 获AIX → 产出Coin Hour → 那耶村消费+AI推理
           ↓
      AIX涨价 → 资本增值 + 继续产出
           ↓
      存储+广告收益 → 现金流叠加

### 六、净收入模型
净收入 = Coin Hour产出(24元/天) + 存储收益 + 广告收益 - Coin Hour消费

### 七、财富自由路径
AIX价格低囤入 → Coin Hour覆盖生活支出 → AIX涨了资本增值 → 存储+广告叠加收益

### 八、一句话总结
AIX Box = 买入入场券 + 持有产出现金流 + 消费覆盖生活 + AIX增值资本收益
本质：买硬件获得生产性资产，不是"买硬件等涨"
