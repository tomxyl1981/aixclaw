### 关键洞察汇总

1. **Everything Claude Code是AIX的技术基座**
   - Skills系统 → AIX Skill平台基础
   - Memory Hooks → 改成UTXO写入
   - Security/AgentShield → Harness实现参考
   - Verification Loops → UTXO校验模板

2. **ProactiveAgent让Box"活起来"**
   - 被动Agent = 工具（用的时候才开）
   - 主动Agent = 管家（一直在想怎么帮你）
   - AIX Box应该是管家，不是工具

3. **OpenMythos是边缘AI突破点**
   - 770M追平1.3B，边缘设备可跑
   - 循环架构天然适配"代码校验LLM"
   - 潜在空间推理保护隐私

4. **Kronos是预测市场引擎**
   - 金融K线专用，比TimesFM更适合
   - mini版4.1M参数，Box能跑
   - "LLM预测+代码执行"完美实践

5. **Mac Studio vs AIX Box**
   - Mac Studio：生产力工具，价值流向法币
   - AIX Box：主权基础设施，价值内循环
   - 组合：M4推理中枢 + N×Box执行节点

6. **Cloudflare Agent就绪度空白**
   - 语义层空白 → UTXO账本天然Agent可读
   - 授权层空白 → 硬件钱包=Agent身份
   - 支付层空白 → Coin Hour=Agent结算货币

7. **Karpathy四原则 = "LLM打工，代码做主"行为规范**
   - Think Before Coding → 不假设、不隐藏困惑
   - Simplicity First → 最小代码解决问题
   - Surgical Changes → 只改必须改的
   - Goal-Driven Execution → 定义成功标准
